StartUp Pro — многостраничный сайт по презентации StartUp_Pro_2026.pdf

Откройте index.html в браузере или через Live Server в VS Code.
Все страницы находятся в одной папке. Фотоматериалы: assets/.
Форма заявки открывает почтовую программу, серверная отправка не подключена.
Google Fonts требует интернет; без сети используется Arial.
Данные кейсов взяты из презентации. Фотографии представлены как изображения исходных слайдов.


V4: бегущая строка — логотипы с безопасным текстовым резервом при недоступности внешних изображений. Global Beverages намеренно текстом. Для полностью офлайн-логотипов требуются реальные файлы: приложенный архив содержит только ссылки, не изображения.
